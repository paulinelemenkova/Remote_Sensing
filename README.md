# Optimising Process Automation of Geospatial Data Pipelines by Artificial Intelligence

LaTeX source for the peer-reviewed article by Polina Lemenkova.

**Published in:** *Facta Universitatis, Series: Automatic Control and Robotics* **2025**, *24*(2), 147–166
**DOI:** https://doi.org/10.22190/FUACR250903011L
**Zenodo:** https://doi.org/10.5281/zenodo.18058578

GeoAI workflow integrating four machine-learning classifiers of the Python scikit-learn library embedded in GRASS GIS — Support Vector Machine (SVM), Decision Tree Classifier (DTC), Random Forest (RF) and Multilayer Perceptron Classifier (MLPC/ANN) — for automated model training, prediction and classification of multispectral Landsat time-series imagery.
